# План проекта Skillaz Start

Статическая интерактивная страница для продуктового плана по релизам 09.09, 07.10, 05.11 и 02.12. Источники собраны из Yandex Tracker, проектного решения Skillaz AI и роадмапа внутренней витрины вакансий.

## Обновление данных

1. Открыть основную страницу и нажать `Администрирование`.
2. Ввести общий пароль доступа.
3. В нужной поставке нажать `Добавить карточку`. Обязательные поля: поставка, направление, название, пользовательский результат, состав и ответственный поток.
4. В блоке продвижения нажать `Добавить карточку`. Обязательные поля: дата, название, формат и аудитория.
5. В блоке методики нажать `Добавить карточку`. Обязательные поля: статус, название и описание; срок можно оставить пустым.
6. В блоке дискавери нажать `Добавить карточку`. Обязательные поля: название, ожидаемый результат, состав, ответственный и статус; таймлайн и ссылки можно добавить позже.
7. Существующие карточки поставок, промо, методики и дискавери по-прежнему можно открыть и отредактировать в режиме администрирования.
8. После сохранения данные записываются в общее защищённое хранилище и сразу становятся доступны всем посетителям.

Сессия редактирования действует четыре часа и хранится только в памяти текущей вкладки. Общий пароль не записывается в код, `localStorage` или ссылку.

Кнопка `Поделиться` формирует актуальную ссылку с параметром `?view=1`, в которой скрыты инструменты администрирования, либо зафиксированный снимок для отчёта.

Статусы также сверяются автоматически по понедельникам, вторникам и средам в 10:00 по Москве. При изменениях обновляется `roadmap-data.js`, выполняется проверка страницы и публикуется новая версия GitHub Pages.

## Данные

Базовый состав фич находится в `roadmap-data.js`. Статусы и проценты на старте являются продуктовой оценкой по состоянию источников на 09.09.2026 и обновляются владельцем плана.

## Квартальный план Q4 2026

- Внутренняя версия: `/q4-2026/` — команды, ёмкость, готовность бэклога и риски.
- Клиентская версия: `/q4-2026/client.html` — очищенный продуктовый план без внутренних данных и ссылок.

## Локальный запуск

```powershell
node server.js
```

Страница доступна по адресу `http://127.0.0.1:8770/`.
