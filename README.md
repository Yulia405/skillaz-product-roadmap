# План проекта Skillaz Start

Статическая интерактивная страница для продуктового плана по релизам 09.09, 07.10 и 05.11. Источники собраны из Yandex Tracker, проектного решения Skillaz AI и роадмапа внутренней витрины вакансий.

## Обновление статусов

1. Открыть страницу без `#snapshot` в адресе.
2. Включить `Режим обновления`.
3. Открыть фичу, изменить статус, готовность и комментарий, затем сохранить.
4. Нажать `Поделиться`: ссылка содержит зафиксированный снимок текущих изменений и открывается только для просмотра.

Изменения владельца сохраняются в `localStorage` текущего браузера. Кнопки скачивания и загрузки в режиме обновления позволяют перенести резервную копию между браузерами.

Статусы также сверяются автоматически по понедельникам, вторникам и средам в 10:00 по Москве. При изменениях обновляется `roadmap-data.js`, выполняется проверка страницы и публикуется новая версия GitHub Pages.

## Данные

Базовый состав фич находится в `roadmap-data.js`. Статусы и проценты на старте являются продуктовой оценкой по состоянию источников на 09.09.2026 и обновляются владельцем плана.

## Локальный запуск

```powershell
node server.js
```

Страница доступна по адресу `http://127.0.0.1:8770/`.
